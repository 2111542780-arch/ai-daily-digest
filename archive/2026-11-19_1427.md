## 🤖 AI / 科技

### 1. PhysScope: Agentic Multimodal Physics Reasoning with Grounded Visual Memory

**来源**: arXiv cs.AI  
**时间**: 1小时前  
**链接**: https://arxiv.org/abs/2611.23010  

视觉语言模型能看懂物理图示，却常把物理约束用错前提致后续计算出错。新方法PhysScope在推理阶段不更新模型权重，把物理适用范围绑定到视觉观察并显式构建派生视图，检查并修正越界前提。这有望提升AI解物理题的可靠性。

### 2. PhysAlign: A Benchmark for Evidence-Grounded Role Alignment in Multimodal Physics Reasoning

**来源**: arXiv cs.AI  
**时间**: 1小时前  
**链接**: https://arxiv.org/abs/2609.33319  

AI领域新增PhysAlign基准，用于评估多模态模型能否将物理示意图的视觉信息正确对应到物理实体、关系与条件，而非仅识别符号数值。该基准分离识别与角色分配，以定位对应错误。值得关注：多模态物理推理的可靠性评估有了更细的切入点。

### 3. Gamer: A Generalist Vision-Language-Action Foundation Model for Long-Horizon Real-Time Game Agent

**来源**: arXiv cs.AI  
**时间**: 1小时前  
**链接**: https://arxiv.org/abs/2611.18397  

AI智能体框架Gamer发布，端到端整合感知、记忆与多步推理，基于数万小时键鼠交互数据训练，可同时适配2D界面与3D模拟环境。其稀疏思考机制显著降低冗余计算，长时程实时游戏代理或向通用具身智能延伸。

### 4. The Only Edge Was Memorized in Training: LLM Trading Agents Around Earnings and Bad News

**来源**: arXiv cs.AI  
**时间**: 1小时前  
**链接**: https://arxiv.org/abs/2611.22177  

arXiv新研究用无前视偏差基准测试LLM交易代理：在598次财报公告前和409次美股大跌后交易，发现其对新闻交易无超额收益，唯一优势是记住了训练数据。这提示LLM炒股能力或被高估。

### 5. When Agent Skills Go Stale: Runtime Behavior and Selective Maintenance in Evolving Environments

**来源**: arXiv cs.AI  
**时间**: 1小时前  
**链接**: https://arxiv.org/abs/2611.22525  

AI智能体的技能状态在环境变化后可能失效：四类任务、两种模型测试显示，旧技能可使任务表现下降超10个百分点，执行成本增加近40%。这提醒需对技能做选择性维护。
